# Bank Customer & Loan Analytics Dashboard 📊

## 📌 Project Overview
This project focuses on designing an end-to-end data analytics solution to evaluate bank customer demographics, loan approval ratios, credit risk profiles, and transactional metrics.

---

## 🛠️ Tech Stack & Tools
- **Database:** MySQL / SQL
- **Visualization:** Power BI, DAX (Data Analysis Expressions)
- **Data Modeling:** Relational Schema (Customers, Accounts, Loans, Transactions)

---

## 🔑 Key Features & Visual Insights
- **KPI Metrics:** Total Customers, Average Age, Total Loan Amount, and Status Breakdown (Approved, Pending, Rejected).
- **Interactive Visuals:** Loan approval rate by account type, geographic distribution by city, and monthly transaction trends.
- **Dynamic Slicers:** Multi-level filtering based on City and Account Type.
